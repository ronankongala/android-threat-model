Comparison with Rekha

Ranganath and Mitra, "Are free Android app security analysis tools effective in detecting known vulnerabilities?", Empirical Software Engineering 2019 (arXiv:1806.09059 v8). The study evaluated 14 vulnerability detection tools on 42 Ghera lean benchmarks. No single tool detected more than 15 of 42.

Tool Benchmarks Precision Recall Notes

Directional comparison only. As docs/notes/evaluation-report.md states, the numbers are not directly comparable. Rekha used an earlier Ghera version with 42 benchmarks; this evaluation uses 53. The precision definitions also differ: Rekha counts per-benchmark verdicts, while here a Secure app with any finding at all counts as a false positive, which pushes precision down.

The Secure APK of MergeManifest-UnintendedBehavior-Lean was not built; its empty secure_findings value is scored as 0 findings, as in the evaluator.
